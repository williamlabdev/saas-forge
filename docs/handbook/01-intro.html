1. 這套 CMS 是什麼

SaaSForge CMS 是一套多租戶的內容管理系統:人透過操作介面編輯與發佈內容,AI agent 透過受限的憑證做同樣的事,而任何會破壞既有內容的結構變更,都必須先變成一張「提案」讓人回答。

1.2 一條內容的生命

  1. 定義結構——建立一個 content type(例如 article),決定它有哪些欄位。
  2. 寫內容——在該 type 下新增 entry,狀態是 draft。
  3. 發佈——把 entry 轉成 published。這一刻它才會出現在 delivery edge。
  4. 改結構——之後要加欄位、刪欄位、改型別時,一律先跑 plan 看影響,再決定直接套用或送出提案。第 6 章。

1.3 只有兩種 entry 狀態

系統刻意只有 draft 與 published,沒有「待審」「排程」這類中間狀態。要下架一篇已發佈的內容,是把它改回 draft——這被視為「止血」,所以權限跟一般編輯相同,不需要發佈權。
